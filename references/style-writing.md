# 写作与学术表达规范

> 权威正本：用户级 `MEMORY.md`「学术论文写作规范」「AI 输出自检协议」两节；技法正本：`chenxiaolei-writing` 技能。本文件是执行速查，不替代正本。

## 一、语体

- 现代白话学术体，不是文言。长句、复句、判断句为主。
- 常用虚词：的、了、在于、实际上、剩下的、而是、据此、由此可见、也就是说。
- 禁用密集堆砌：者、之、亦、故、须、宜、乃、方为、方能。命题者、学习者、笔者这类名词除外。
- 此前两轮误写为手册清单体和文言体，均已纠正，不得回退。

## 二、去 AI 味

- 学术论文写作必跑 `humanizer` 技能。
- 禁破折号连缀；少用不是 X 而是 Y；不用真正、核心在于类虚饰。
- 不写单句成段的金句收尾；不三连排比成段。

## 三、引号与数字

- 引号极简：只用于政策原文、文献直接引语、自造术语首次界定、题面直接引语。
- 密度约 1 对 / 250 字。
- 数字一律阿拉伯数字，按 GB/T 15835；数字与汉字间不加空格。

## 四、投稿硬指标（《北京教育学院学报》口径）

| 项 | 指标 |
|---|---|
| 篇名 | ≤ 20 字 |
| 摘要 | 200—300 字，第三人称，禁本文/本研究/作者作主语，禁通过、分析了 |
| 关键词 | 3—5 个 |
| 正文 | 8000 字以上 |
| 层次 | 一、／（一）／1. |
| 参考文献 | 顺序编码制，GB/T 7714—2015，条条须在正文有对应引用 |

## 五、概念一致性

- 题目与内容的概念域必须统一。
- 两个易混术语，例如项目式与跨学科，须先设一节做维度分辨，再全文统一用词，不得互代。
- 学某刊风格前必须先抓正文原文。只凭目录与摘要猜语体必然猜偏。
- 可用路径：该刊微信公众号转载页、国家哲学社会科学文献中心。

## 六、交付前自检（每次实质性回答必跑）

1. 事实或数据是否未经核实。
2. 是否把推断说成事实。
3. 是否遗漏关键前提或反例。
4. 是否因果倒置、样本不足、过度概括。
5. 是否因提问带倾向而顺竿爬。

每个风险点写四要素：错误概率；出错原因；需要什么证据确认；是否改变最终结论。找不到真实风险就直说，不凑数。

## 七、行业顶级专家视角再审

- 选 1—3 个专家身份，至少含一个最对口视角和一个交叉视角。
- 常备角色：教学教研专家、顶尖视觉/信息设计专家、信息架构师、方法学统计审查员、领域权威。
- 每个角色独立挑刺，然后回一手材料印证，最后直接改产物。
- 交付说明写明以哪个专家视角再审、改了哪几处。只写建议不改，视为未执行。
