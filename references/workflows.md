## 二、GitHub-first 留痕四行

```
工具检索：GitHub 搜「关键词A / 关键词B」，看 N 个仓库（owner/repo1、owner/repo2）
采纳：owner/repo — 取其 X 原则（未安装、未复制代码 / 已核 MIT）
放弃：owner/repo — 原因（许可不明 / 依赖过重 / 与既定规范冲突）
自研：某部分因何自写（比引入更短 / 无可用实现）
```

检索命令：

```bash
python ~/.workbuddy/skills/github-tool-first/scripts/find_tools.py "关键词" --domain agent-skill --min-stars 30 --limit 8
```

判定四问：许可是否允许、依赖是否可控、近 12 个月是否维护、自研是否更短。三档取用：取原则、取代码、整用。取原则优先。

## 三、书籍蒸馏三件套

输出 `<workspace>/outputs/`：

1. `《书名》 证据型知识库.html`：单文件，8 视图，四层图谱。
2. `《书名》 知识萃取表.xlsx`：6 sheet，含知识条目、模型库、证据矩阵、章节概览、可落地工具族、使用说明。
3. `《书名》 蒸馏总纲.md`：编论证链、分编章目、模型总表、争议清单、三条使用路径。

字段：13 标准字段 + 4 定位字段 + 5 归类字段。文献评述型书籍必须区分本书作者判断与被评述学者结论。

图谱硬标准：双层力导向，章节枢纽按 Part 配色，概念节点挂到出现章节；必须可鼠标拖拽、点击节点加载或减载关系网、松手回落收敛；布局铺满画布。

## 四、网页产出必附 Excel 并回存 ima

顺序：网页 → Excel → 回存 ima。

Excel：多 sheet，微软雅黑，首行深蓝底白字表头，冻结首行，自动换行。openpyxl 3.1.5 可用。

ima 回存链路：

1. `create_media`，MIME 按扩展名精确填写。
2. COS 签名 PUT 上传，HTTP method 用小写 put，签名包含 `x-cos-security-token`。
3. `add_knowledge`，传 `media_id` 与 `knowledge_base_id`，同名用 REPLACE。

目标库：`ima_kb_y2DGgmxK`。文件夹只能在 ima 客户端建，`folder_id` 只在入库那一刻生效。HTML 无法按 media_type 筛出，刚入库搜不到要说解析中。凭证明文用完立刻删。

上传后必须报存到哪个库、哪个文件夹、成功几条几 MB。

## 五、智库周报

五板块：外交 #0E3F8C、军事 #C0392B、经贸 #1F8A8A、产业科技 #6C4FB0、能源 #C9962B。每板块只取跨源聚合前 5 条高频信号。分析框架用生产力布局与权力格局的物质逻辑，不用西方意识形态话语。产物中去除去叙事化、非机构立场、学术表达规范等思路化标签词。落盘 `智库周报/`，HTML + Markdown 双产物。

## 六、PBL 萃取

固定 5 模块：子标题、理论、案例、反思、可迁移动作。按小学、初中、高中学段校际轮转。沉淀到 ima 的 PBL 萃取文件夹。

## 七、学校管理材料

家长面谈、制度补漏、请愿回应等，交付物为可打印提纲与表格。每一点必须附法律依据或学校内部管理依据。学生信息一律化名。不写无依据的承诺。

## 八、自动化任务

跨机复刻唯一可靠方式：把任务全文，即名称、频率、prompt，抄进用户级 `MEMORY.md`，再在新机器按此重建。定时任务不随账号同步，`cwds` 指向本机路径，存在本机 `~/.workbuddy/workbuddy.db` 的 automations 表。

## 九、交付前清单

- 层级成环，页面顺序与四环一致。
- 每页有结论也有策略。
