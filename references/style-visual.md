# 视觉与版式规范

> 来源：`academic-ppt-style` 技能；ima 知识库「多巴胺风格PPT配色方案.md」「AIFA风格PPT样式指南.md」「中国风知识长图·视觉风格规范v1.0.md」；用户级 `MEMORY.md`「网页看板统一框架」节。

## 一、PPT 默认：学术风格

| 项 | 规范 |
|---|---|
| 主色 | 深蓝 #0E3F8C、蓝 #1E4FA8、亮蓝 #3D7BD9；最深海军 #0E2841 |
| 正文 | 石板灰 #4A5568；次级灰 #8B97A8 |
| 卡片 | #F7F9FC / #E8EFF8；描边 #D6DCE5 |
| 强调 | 琥珀 #FFC107、珊瑚红 #D9534F、红 #FF0000，仅用于关键数字或警示 |
| 字体 | 微软雅黑全篇统一，不用等线或宋体 |
| 字号 | 封面主标 46pt；分隔页大数字 150pt、章节名 39pt；标题条 24pt 白字；子标题 15—20pt 深蓝加粗；正文 12—14pt；页脚 10—11pt |
| 版式 | 封面 → 目录 → 大数字分隔页 → 内容页 → 框架页 → 附录 → 结尾 |

调性：深蓝加灰，少量琥珀，克制学术风。不炫图，不滥渐变。左对齐为主，页脚含单位与页码。

## 二、PPT 变体：多巴胺配色

仅在教师培训、AI 赋能、年轻教师场、德育生活化主题中启用。铁律 60-30-10：60% 中性基底，30% 次级色，10% 高饱和点缀。正文与表格文字仍用深墨或白。

| 方案 | 场景 | 基底 | 主强调 | 辅色 |
|---|---|---|---|---|
| A 果漾多巴胺 | 培训开场、激励、生活化 | #FFF8F0 | #FF7A00 | #FFD000、#FF6F91、#00D9A3、#3A86FF |
| B 电光霓虹 | AI、信息化、路演 | #160E2E | #3A86FF | #7B61FF、#FF5FA2、#33FF99、#FF7A00 |
| C 糖果马卡龙 | 小初段、德育、心理 | #FBFBFD | #FF6F91 | #A2DFF7、#FF9A8B、#EAB8E4、#00D9A3 |

骨架不变，只换颜色令牌。AIFA 深色风到方案 B 是零成本迁移。字体仍为微软雅黑加楷体引用。

## 三、中国风知识长图

触发：画图、做个图、信息长图、知识梳理类图表、报告配图、公众号封面长图。例外：用户明确要求深色、科技感、商务风或其他配色。

一句话：宣纸底色 + 朱红印章 + 朝代分色 + 织锦卡片 + 竖排水印 + 书法笔触。

- 主色：墨黑 #1C1916，淡墨 #4A4238，宣纸 #EFE7D6，朱印红 #A8352A，赭金 #B08034。
- 朝代六色：#C4884A、#B5443A、#2E7B78、#3F7CA8、#5C4E92、#B08A2E。
- 中文主体用宋体，英文副标用无衬线。1080px 基准宽，2 倍图输出。
- 四层质感：宣纸纤维、暗角、装裱边框、底部远山。
- 图表标签必须做碰撞检测；左右两栏用独立纵向流，不用 stretch 硬拉。
- 数据层与渲染层分离，内容写在 `const DATA` 里。

## 四、网页看板

横向四环加一附：为什么（判断层＋根据层）→ 是什么 → 怎么做 → 反拨意义 → 附：方法与局限。理论页必须紧跟总览，不得放到反拨之后。

每页三段式：

1. 数据说了什么，1—2 句结论加 KPI 卡。
2. 多层次可视化，图、表、矩阵至少两种，交叉印证同一结论。
3. 策略与建议 3 条，每条写法加依据数字加检验方式。

证据纪律：评分、评语、过程数据三源同向才写结论；相左的单列错位发现。推断标 C1 已核／C2 推断／C3 待核。口径写进方法页。

视觉：主色 #0E3F8C，辅 #1E4FA8 / #3D7BD9；标题宋体，正文微软雅黑；数字 tabular-nums 右对齐；颜色全走 CSS 变量，SVG 富文本用 `style="fill:var(--x)"`。浅深双主题，单文件离线，零外部依赖。

## 五、图表纪律

- 标题写发现，不写变量名。
- 直接标注优先于图例；去顶框和右框线；网格线不画或仅横向低透明度。
- 禁 3D、禁渐变填充、禁饼图。
- 每图必须有对照物：均值线、参考线，或同主题另一节。
- 每图给 aria-label 写明关键发现；动效尊重 prefers-reduced-motion，200—500ms。
- 反模板化：不要大数字加小标签加渐变套版；一页只留一个记忆点。

## 六、技术坑

- `@media print` 必须写在所有 `@media(max-width)` 之后。
- 打印封面加 `page-break-after:always` 独立成页。
- 多段字符串拼 HTML 易漏 f 前缀，交付前扫 `\{[A-Za-z_]+[\[}]`，应为 0。
- 词频结论必须写清口径，全量与建议类数值可差近一半。
- 列表类 UI 必须断言条目数量，不能只断言标题文案。
- Edge headless 截图可能被拦，须确认 PNG 真存在；被拦则改 DOM 冒烟测试并如实说明。
